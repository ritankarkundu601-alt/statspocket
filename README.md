# StatsPocket

A zero-dependency, mobile-friendly statistics toolkit for students. The app runs entirely in your browser.

## Run locally

Open `index.html` in a modern browser. No install, API key, or backend is required.

## Included tools

- Descriptive statistics: count, mean, median, mode, variance, standard deviation, quartiles, range, and interquartile range. Choose population or sample variance. Quartiles use linear interpolation at positions `(n − 1)p`.
- Probability: binomial and Poisson point probabilities, plus the normal cumulative probability `P(X ≤ x)`.
- Correlation and simple linear regression: Pearson correlation, `R²`, slope, intercept, and fitted line.
- A frequency chart for the descriptive-statistics dataset.

## GitHub Pages

The app entry point is `index.html` at the repository root, ready for GitHub Pages. To publish, configure the repository's Pages source to deploy the `main` branch from `/(root)` in **Settings → Pages**. Saving that setting publishes the website publicly; do this only when you are ready to launch.

## Note

StatsPocket is an educational MVP, not a validated statistical package. Verify calculations against trusted references before using results for assessed or professional work.
